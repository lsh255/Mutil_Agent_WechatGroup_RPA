# 方案1：基于UFO Constellation模式的任务分解架构

## 1. 架构概述

本方案基于UFO³的Constellation DAG任务分解模式，在保留现有单Agent工作流的基础上，引入全局协调器实现多智能体协作。核心思想是将复杂业务场景声明式分解为动态DAG任务图，通过事件驱动的编排引擎实现异步执行和自适应调整。

### 1.1 设计理念

| 核心概念 | UFO³概念 | 本项目实现 |
|---------|---------|-----------|
| **ConstellationAgent** | 全局协调器，分解用户意图为DAG | ConstellationAgent，分解用户工作安排和群聊监控需求 |
| **TaskStars** | DAG任务节点，包含依赖关系 | LangGraph节点，包含单Agent工作流节点和新增交互节点 |
| **Constellation Orchestrator** | 事件驱动编排引擎 | LangGraph StateGraph + Redis事件总线 |
| **Graph Evolution** | 结果驱动的图演化 | 条件分支动态调整，根据任务状态重排DAG |

## 2. 核心组件设计

### 2.1 ConstellationAgent（全局协调器）

**职责：**
1. 接收前端用户请求（工作安排、群聊配置、登录请求等）
2. 解析用户意图，生成DAG任务图
3. 使用LangGraph Send API分发任务到各Agent
4. 监控任务执行状态，动态调整DAG

**状态定义：**

```python
class ConstellationState(TypedDict):
    user_request: Optional[UserRequest]           # 用户请求
    dag_graph: Optional[Dict[str, Any]]          # DAG任务图
    task_executions: Dict[str, TaskExecution]     # 任务执行状态
    messages: Annotated[list, add_messages]       # 消息记录
    context: Dict[str, Any]                       # 上下文信息

class UserRequest(TypedDict):
    request_type: RequestType                    # 请求类型
    payload: Dict[str, Any]                      # 请求负载
    user_id: str                                  # 用户ID

class TaskExecution(TypedDict):
    task_id: str                                  # 任务ID
    agent_type: str                               # Agent类型
    status: TaskStatus                            # 任务状态
    result: Optional[Dict[str, Any]]             # 执行结果
    dependencies: List[str]                       # 依赖任务ID
```

**DAG生成逻辑：**

```python
class DAGBuilder:
    @staticmethod
    def build_from_request(user_request: UserRequest) -> Dict[str, Any]:
        if user_request["request_type"] == RequestType.SANDBOX_LOGIN:
            return DAGBuilder._build_login_dag()
        elif user_request["request_type"] == RequestType.WORKFLOW_START:
            return DAGBuilder._build_workflow_dag(user_request["payload"])
        elif user_request["request_type"] == RequestType.WORK_ARRANGEMENT:
            return DAGBuilder._build_arrangement_dag(user_request["payload"])
    
    @staticmethod
    def _build_login_dag() -> Dict[str, Any]:
        return {
            "nodes": [
                {"id": "sandbox_auth", "agent": "SandboxAuthAgent", "parallel": False},
                {"id": "user_feedback", "agent": "UserFeedbackAgent", "parallel": False}
            ],
            "edges": [
                {"from": "sandbox_auth", "to": "user_feedback"}
            ]
        }
    
    @staticmethod
    def _build_workflow_dag(payload: Dict[str, Any]) -> Dict[str, Any]:
        monitor_nodes = [
            {"id": f"monitor_{i}", "agent": "MonitorAgent", "group": payload["group_names"][i]}
            for i in range(len(payload["group_names"]))
        ]
        
        return {
            "nodes": [
                *monitor_nodes,
                {"id": "multimodal", "agent": "MultimodalAgent", "parallel": True},
                {"id": "tracker", "agent": "TrackerAgent", "parallel": True},
                {"id": "document", "agent": "DocumentAgent", "parallel": True}
            ],
            "edges": [
                {"from": node["id"], "to": "multimodal"} for node in monitor_nodes
            ] + [
                {"from": "multimodal", "to": "tracker"},
                {"from": "tracker", "to": "document"}
            ]
        }
```

### 2.2 新增Agent设计

#### 2.2.1 SandboxAuthAgent（沙盒认证Agent）

**职责：**
1. 检查微信沙盒容器状态
2. 触发微信登录流程
3. 通知前端用户扫码登录

**工作流节点：**

```python
class SandboxAuthNode:
    @staticmethod
    def process(state: ConstellationState) -> Dict[str, Any]:
        user_request = state.get("user_request")
        
        container_manager = SandboxManager()
        is_running = container_manager.check_container_status(user_request["user_id"])
        
        if not is_running:
            container_manager.start_container(user_request["user_id"])
        
        login_status = container_manager.check_login_status(user_request["user_id"])
        
        if login_status == "need_scan":
            return {
                "messages": [("system", "微信需要扫码登录")],
                "context": {"need_user_interaction": True, "vnc_url": container_manager.get_vnc_url(user_request["user_id"])}
            }
        elif login_status == "logged_in":
            return {
                "messages": [("system", "微信已登录")],
                "context": {"need_user_interaction": False}
            }
        
        return {"messages": [("system", "等待微信启动...")]}
```

#### 2.2.2 UserFeedbackAgent（用户反馈Agent）

**职责：**
1. 通过WebSocket向前端推送交互请求
2. 接收用户反馈（扫码确认、意图确认等）
3. 将用户反馈返回给ConstellationAgent

**工作流节点：**

```python
class UserFeedbackNode:
    @staticmethod
    async def process(state: ConstellationState) -> Dict[str, Any]:
        context = state.get("context", {})
        
        if context.get("need_user_interaction"):
            websocket_manager = WebSocketManager()
            user_id = state["user_request"]["user_id"]
            
            feedback = await websocket_manager.request_feedback(
                user_id=user_id,
                interaction_type="scan_qrcode",
                payload={"vnc_url": context.get("vnc_url")}
            )
            
            if feedback.get("status") == "completed":
                return {
                    "messages": [("system", "用户已完成扫码登录")],
                    "context": {"login_completed": True}
                }
        
        return {"context": {}}
```

#### 2.2.3 TrackerAgent（状态跟踪Agent）

**职责：**
1. 维护任务状态（替代原有StateTrackerNode）
2. 判断任务是否完成
3. 决定是否生成文档

**状态定义：**

```python
class TaskStatusState(TypedDict):
    task_id: str                                   # 任务ID
    work_item: str                                 # 事项名称
    work_id: str                                   # 作业ID
    phase: TaskPhase                               # 任务阶段
    completed_phases: List[TaskPhase]             # 已完成阶段
    all_phases_required: bool                      # 是否要求全部阶段
    messages: List[str]                           # 关联消息ID
```

**工作流节点：**

```python
class TrackerNode:
    @staticmethod
    def process(state: AgentState) -> Dict[str, Any]:
        multimodal_analysis = state.get("multimodal_analysis")
        
        task_status = TaskStatusState(
            task_id=multimodal_analysis.get("task_id"),
            work_item=multimodal_analysis.get("work_item"),
            work_id=multimodal_analysis.get("work_id"),
            phase=multimodal_analysis.get("phase"),
            completed_phases=[],
            all_phases_required=multimodal_analysis.get("all_phases_required", True),
            messages=[state["raw_message"]["id"]]
        )
        
        redis_client = RedisClient()
        stored_status = redis_client.get_task_status(
            user_id=state["raw_message"]["sender"],
            task_id=task_status["task_id"],
            work_id=task_status["work_id"]
        )
        
        if stored_status:
            task_status["completed_phases"] = stored_status["completed_phases"]
        
        if task_status["phase"] not in task_status["completed_phases"]:
            task_status["completed_phases"].append(task_status["phase"])
        
        redis_client.save_task_status(
            user_id=state["raw_message"]["sender"],
            task_id=task_status["task_id"],
            work_id=task_status["work_id"],
            status=task_status
        )
        
        is_complete = (
            len(task_status["completed_phases"]) == 3 or
            not task_status["all_phases_required"] and len(task_status["completed_phases"]) >= 1
        )
        
        return {
            "task_status": task_status,
            "context": {"should_generate_document": is_complete}
        }
```

### 2.3 DAG编排引擎

**工作流定义：**

```python
def create_constellation_workflow():
    workflow = StateGraph(ConstellationState)
    
    workflow.add_node("intent_parser", intent_parser_node.parse)
    workflow.add_node("dag_builder", dag_builder_node.build)
    workflow.add_node("task_orchestrator", task_orchestrator_node.orchestrate)
    workflow.add_node("result_collector", result_collector_node.collect)
    
    workflow.set_entry_point("intent_parser")
    
    workflow.add_edge("intent_parser", "dag_builder")
    workflow.add_edge("dag_builder", "task_orchestrator")
    workflow.add_edge("task_orchestrator", "result_collector")
    
    workflow.add_conditional_edges(
        "result_collector",
        result_collector_node.should_continue,
        {"continue": "task_orchestrator", "end": END}
    )
    
    return workflow.compile(checkpointer=RedisCheckpointer())
```

**任务分发逻辑：**

```python
class TaskOrchestratorNode:
    @staticmethod
    async def orchestrate(state: ConstellationState) -> Dict[str, Any]:
        dag_graph = state.get("dag_graph")
        task_executions = state.get("task_executions", {})
        
        ready_tasks = TaskOrchestratorNode._get_ready_tasks(dag_graph, task_executions)
        
        for task in ready_tasks:
            if task["agent"] == "SandboxAuthAgent":
                await TaskOrchestratorNode._dispatch_sandbox_auth_task(task, state)
            elif task["agent"] == "MonitorAgent":
                await TaskOrchestratorNode._dispatch_monitor_task(task, state)
            elif task["agent"] == "MultimodalAgent":
                await TaskOrchestratorNode._dispatch_multimodal_task(task, state)
        
        return {"task_executions": task_executions}
    
    @staticmethod
    def _get_ready_tasks(dag_graph: Dict, executions: Dict) -> List[Dict]:
        ready_tasks = []
        
        for node in dag_graph["nodes"]:
            task_id = node["id"]
            
            if task_id not in executions:
                dependencies_met = all(
                    dep in executions and executions[dep]["status"] == "completed"
                    for dep in TaskOrchestratorNode._get_dependencies(task_id, dag_graph)
                )
                
                if dependencies_met:
                    ready_tasks.append(node)
        
        return ready_tasks
    
    @staticmethod
    async def _dispatch_sandbox_auth_task(task: Dict, state: ConstellationState):
        single_agent_workflow = create_single_agent_workflow()
        config = {"configurable": {"thread_id": state["user_request"]["user_id"]}}
        
        await single_agent_workflow.ainvoke(
            {"user_request": state["user_request"]},
            config
        )
```

## 3. 数据流转设计

### 3.1 单Agent模式数据流（向后兼容）

```
WeChat Sandbox → Redis Streams → AgentConsumer → 
MonitorNode → MultimodalNode → StateTrackerNode → DocumentNode → END
```

### 3.2 多Agent模式数据流

```
前端用户请求 → ConstellationAgent → DAG生成 → 
TaskOrchestrator分发任务 → 各Agent并行执行 → 
结果收集 → 动态调整DAG → 返回前端
```

### 3.3 混合模式数据流

```
前端配置 → ConstellationAgent生成监控DAG → 
MonitorAgent消费SSE流 → MultimodalAgent分析 → 
TrackerAgent跟踪 → DocumentAgent执行 → 
前端实时接收状态更新
```

## 4. 兼容性设计

### 4.1 单Agent工作流保持不变

- monitor_node.py、multimodal_node.py、state_tracker_node.py、document_node.py保持原有实现
- AgentConsumer继续独立运行，向后兼容
- 无前端交互时，自动进入单Agent模式

### 4.2 多Agent工作流作为扩展

- 新增SandboxAuthAgent、UserFeedbackAgent、TrackerAgent
- ConstellationAgent作为可选组件，根据用户请求动态加载
- 使用LangGraph Send API实现Agent间通信

### 4.3 状态共享机制

- Redis Checkpointer实现跨Agent状态共享
- thread_id格式：{user_id}:{session_id}
- 状态键格式：state:{thread_id}:{checkpoint_id}

## 6. 优势与劣势

### 优势

| 维度 | 说明 |
|------|------|
| **兼容性** | 完全保留单Agent工作流，向后兼容 |
| **扩展性** | DAG动态调整，支持复杂业务场景 |
| **可视化** | DAG结构清晰，易于监控和调试 |
| **并行执行** | 支持多群聊并行监控，提高效率 |
| **容错性** | 单节点失败不影响整体流程，支持重试 |

### 劣势

| 维度 | 说明 |
|------|------|
| **复杂度** | DAG编排增加系统复杂度 |
| **学习成本** | 需要理解LangGraph Send API和DAG概念 |
| **状态管理** | 跨Agent状态同步需要额外设计 |
| **调试难度** | 并行执行增加问题定位难度 |
