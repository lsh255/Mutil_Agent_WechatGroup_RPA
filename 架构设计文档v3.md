# 架构设计文档 v3

## 1. 架构概述

### 1.1 设计理念

本项目采用 **UFO Constellation DAG任务分解模式**，在保留现有单Agent工作流的基础上，引入全局协调器实现多智能体协作。基于 **LangGraph** 构建有状态的多智能体工作流系统，通过 **Redis Streams** 实现异步消息传递，通过 **ChromaDB** 实现知识库存储与RAG检索。

**架构演进：**
- **v2（原架构）**: Orchestrator-Worker（协调器-工作器）模式，单Agent工作流
- **v3（新架构）**: UFO Constellation模式，动态DAG任务分解，支持多Agent交互

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| 状态驱动 | LangGraph状态机驱动工作流流转 |
| 异步解耦 | Redis Streams实现服务间解耦通信 |
| 智能编排 | 多Agent协同处理复杂业务场景 |
| 容错设计 | 检查点机制支持工作流恢复 |
| DAG任务分解 | ConstellationAgent将用户意图分解为动态DAG任务图 |
| 图演化机制 | 根据任务执行结果动态调整DAG结构 |
| 向后兼容 | 保留原有单Agent工作流，支持轻量模式 |
| 前端交互 | WebSocket实时通信，支持用户扫码登录和意图确认 |

## 2. 核心架构模块

### 2.1 LangGraph工作流编排层

#### 2.1.1 工作流架构

本架构支持两种工作流模式，通过配置切换：

| 模式 | 适用场景 | 特点 |
|------|---------|------|
| **单Agent模式** | 轻量监控，无需用户交互 | 向后兼容，资源占用低 |
| **多Agent模式** | 复杂场景，需要用户交互 | 支持前端交互，任务动态分解 |

#### 2.1.2 单Agent工作流（向后兼容）

**工作流定义：**

```python
def create_single_agent_workflow():
    workflow = StateGraph(AgentState)
    
    # 添加节点
    workflow.add_node("monitor", monitor_node.process)
    workflow.add_node("multimodal", multimodal_node.analyze)
    workflow.add_node("state_tracker", state_tracker_node.update)
    workflow.add_node("document", document_node.execute)
    
    # 设置入口
    workflow.set_entry_point("monitor")
    
    # 添加边
    workflow.add_edge("monitor", "multimodal")
    workflow.add_edge("multimodal", "state_tracker")
    
    # 条件分支
    workflow.add_conditional_edges(
        "state_tracker",
        state_tracker_node.should_generate_document,
        {"yes": "document", "no": END}
    )
    
    return workflow.compile()
```

**工作流节点职责：**

| 节点 | 职责 | 输入 | 输出 |
|------|------|------|------|
| **MonitorNode** | 接收原始消息，载入工作流状态 | RawMessage | System消息日志 |
| **MultimodalNode** | 多模态分析，调用AI模型识别任务类型 | RawMessage | MultimodalAnalysis |
| **StateTrackerNode** | 更新任务状态，判断工作流走向 | MultimodalAnalysis | TaskStatus + 路由决策 |
| **DocumentNode** | 执行文档更新操作 | DocumentUpdate | 执行结果 |

#### 2.1.3 多Agent工作流（UFO Constellation）

**ConstellationAgent工作流定义：**

```python
def create_constellation_workflow():
    workflow = StateGraph(ConstellationState)
    
    workflow.add_node("intent_parser", intent_parser_node.parse)
    workflow.add_node("dag_builder", dag_builder_node.build)
    workflow.add_node("task_orchestrator", task_orchestrator_node.orchestrate)
    workflow.add_node("result_collector", result_collector_node.collect)
    
    workflow.set_entry_point("intent_parser")
    
    workflow.add_edge("intent_parser", "dag_builder")
    workflow.add_edge("dag_builder", "task_orchestrator")
    workflow.add_edge("task_orchestrator", "result_collector")
    
    workflow.add_conditional_edges(
        "result_collector",
        result_collector_node.should_continue,
        {"continue": "task_orchestrator", "end": END}
    )
    
    return workflow.compile(checkpointer=RedisCheckpointer())
```

**ConstellationAgent节点职责：**

| 节点 | 职责 | 输入 | 输出 |
|------|------|------|------|
| **IntentParserNode** | 解析用户请求意图 | UserRequest | ParsedIntent |
| **DAGBuilderNode** | 根据意图生成DAG任务图 | ParsedIntent | DAGGraph |
| **TaskOrchestratorNode** | 分发任务到各Agent | DAGGraph | TaskExecutions |
| **ResultCollectorNode** | 收集任务执行结果 | TaskExecutions | FinalResult |

#### 2.1.4 状态定义

**AgentState（单Agent模式）：**

```python
class AgentState(TypedDict):
    raw_message: Optional[RawMessage]           # 原始消息
    multimodal_analysis: Optional[MultimodalAnalysis]  # 多模态分析结果
    task_status: Optional[TaskStatus]           # 任务状态
    document_updates: List[DocumentUpdate]      # 文档更新指令
    messages: Annotated[list, add_messages]     # 消息记录
    context: Dict[str, Any]                     # 上下文信息
```

**ConstellationState（多Agent模式）：**

```python
class ConstellationState(TypedDict):
    user_request: Optional[UserRequest]           # 用户请求
    dag_graph: Optional[Dict[str, Any]]          # DAG任务图
    task_executions: Dict[str, TaskExecution]     # 任务执行状态
    messages: Annotated[list, add_messages]       # 消息记录
    context: Dict[str, Any]                       # 上下文信息

class UserRequest(TypedDict):
    request_type: RequestType                    # 请求类型
    payload: Dict[str, Any]                      # 请求负载
    user_id: str                                  # 用户ID

class TaskExecution(TypedDict):
    task_id: str                                  # 任务ID
    agent_type: str                               # Agent类型
    status: TaskStatus                            # 任务状态
    result: Optional[Dict[str, Any]]             # 执行结果
    dependencies: List[str]                       # 依赖任务ID

class TaskStatusState(TypedDict):
    task_id: str                                   # 任务ID
    work_item: str                                 # 事项名称
    work_id: str                                   # 作业ID
    phase: TaskPhase                               # 任务阶段
    completed_phases: List[TaskPhase]             # 已完成阶段
    all_phases_required: bool                      # 是否要求全部阶段

```

**智能体解耦说明（MonitorAgent重构）：**

原MonitorAgent的核心职责已解耦为两个独立智能体：

- **SandboxManagerAgent**（容器管理智能体）:
  - 管理微信沙盒Docker容器的生命周期（创建、启动、停止、删除）
  - 监控容器健康状态
  - 提供容器状态查询接口
  - 管理容器端口映射和数据卷
  - 支持多用户多容器模式（按user_id区分）
  - 支持容器健康检查和自动重启
  - 支持容器状态持久化（Redis）

- **SSEProcessorAgent**（SSE信息流处理智能体）:
  - 连接到wechat_sandbox的SSE流
  - 验证消息格式和内容（消息接收、验证）
  - 消费消息并进行处理（消息消费）
  - 转发消息给Orchestrator工作流（消息转发）
  - 支持消息过滤、路由和转换
  - 提供消息统计和监控
  - 支持自定义消息处理回调
  - 支持消息去重和限流

#### 2.2.5 多Agent智能体架构（UFO Constellation）

**SandboxAuthAgent架构：**

```python
class SandboxAuthNode:
    @staticmethod
    def process(state: ConstellationState) -> Dict[str, Any]:
        user_request = state.get("user_request")
        
        container_manager = SandboxManager()
        is_running = container_manager.check_container_status(user_request["user_id"])
        
        if not is_running:
            container_manager.start_container(user_request["user_id"])
        
        login_status = container_manager.check_login_status(user_request["user_id"])
        
        if login_status == "need_scan":
            return {
                "messages": [("system", "微信需要扫码登录")],
                "context": {"need_user_interaction": True, "vnc_url": container_manager.get_vnc_url(user_request["user_id"])}
            }
        elif login_status == "logged_in":
            return {
                "messages": [("system", "微信已登录")],
                "context": {"need_user_interaction": False}
            }
        
        return {"messages": [("system", "等待微信启动...")]}
```

**UserFeedbackAgent架构：**

```python
class UserFeedbackNode:
    @staticmethod
    async def process(state: ConstellationState) -> Dict[str, Any]:
        context = state.get("context", {})
        
        if context.get("need_user_interaction"):
            websocket_manager = WebSocketManager()
            user_id = state["user_request"]["user_id"]
            
            feedback = await websocket_manager.request_feedback(
                user_id=user_id,
                interaction_type="scan_qrcode",
                payload={"vnc_url": context.get("vnc_url")}
            )
            
            if feedback.get("status") == "completed":
                return {
                    "messages": [("system", "用户已完成扫码登录")],
                    "context": {"login_completed": True}
                }
        
        return {"context": {}}
```

        multimodal_analysis = state.get("multimodal_analysis")
        
        task_status = TaskStatusState(
            task_id=multimodal_analysis.get("task_id"),
            work_item=multimodal_analysis.get("work_item"),
            work_id=multimodal_analysis.get("work_id"),
            phase=multimodal_analysis.get("phase"),
            completed_phases=[],
            all_phases_required=multimodal_analysis.get("all_phases_required", True),
            messages=[state["raw_message"]["id"]]
        )
        
        redis_client = RedisClient()
        stored_status = redis_client.get_task_status(
            user_id=state["raw_message"]["sender"],
            task_id=task_status["task_id"],
            work_id=task_status["work_id"]
        )
        
        if stored_status:
            task_status["completed_phases"] = stored_status["completed_phases"]
        
        if task_status["phase"] not in task_status["completed_phases"]:
            task_status["completed_phases"].append(task_status["phase"])
        
        redis_client.save_task_status(
            user_id=state["raw_message"]["sender"],
            task_id=task_status["task_id"],
            work_id=task_status["work_id"],
            status=task_status
        )
        
        is_complete = (
            len(task_status["completed_phases"]) == 3 or
            not task_status["all_phases_required"] and len(task_status["completed_phases"]) >= 1
        )
        
        return {
            "task_status": task_status,
            "context": {"should_generate_document": is_complete}
        }
```

class DAGBuilder:
    @staticmethod
    def build_from_request(user_request: UserRequest) -> Dict[str, Any]:
        if user_request["request_type"] == RequestType.SANDBOX_LOGIN:
            return DAGBuilder._build_login_dag()
        elif user_request["request_type"] == RequestType.WORKFLOW_START:
            return DAGBuilder._build_workflow_dag(user_request["payload"])
        elif user_request["request_type"] == RequestType.WORK_ARRANGEMENT:
            return DAGBuilder._build_arrangement_dag(user_request["payload"])
    
    @staticmethod
    def _build_login_dag() -> Dict[str, Any]:
        return {
            "nodes": [
                {"id": "sandbox_auth", "agent": "SandboxAuthAgent", "parallel": False},
                {"id": "user_feedback", "agent": "UserFeedbackAgent", "parallel": False}
            ],
            "edges": [
                {"from": "sandbox_auth", "to": "user_feedback"}
            ]
        }
    
    @staticmethod
    def _build_workflow_dag(payload: Dict[str, Any]) -> Dict[str, Any]:
        sse_processor_nodes = [
            {"id": f"sse_processor_{i}", "agent": "SSEProcessorAgent", "group": payload["group_names"][i]}
            for i in range(len(payload["group_names"]))
        ]
        
        return {
            "nodes": [
                *sse_processor_nodes,
                {"id": "multimodal", "agent": "MultimodalAgent", "parallel": True},
                {"id": "tracker", "agent": "TrackerAgent", "parallel": True},
                {"id": "document", "agent": "DocumentAgent", "parallel": True}
            ],
            "edges": [
                {"from": node["id"], "to": "multimodal"} for node in sse_processor_nodes
            ] + [
                {"from": "multimodal", "to": "tracker"},
                {"from": "tracker", "to": "document"}
            ]
        }

class WebSocketManager:
    """WebSocket管理器，支持用户交互"""
    
    def __init__(self):
        self.active_connections: Dict[str, WebSocket] = {}
    
    async def connect(self, websocket: WebSocket, user_id: str):
        """建立WebSocket连接"""
        await websocket.accept()
        self.active_connections[user_id] = websocket
    
    def disconnect(self, user_id: str):
        """断开WebSocket连接"""
        if user_id in self.active_connections:
            del self.active_connections[user_id]
    
    async def send_message(self, user_id: str, message: dict):
        """发送消息给指定用户"""
        if user_id in self.active_connections:
            websocket = self.active_connections[user_id]
            await websocket.send_json(message)
    
    async def request_feedback(self, user_id: str, interaction_type: str, payload: dict) -> dict:
        """请求用户反馈"""
        request_id = str(uuid.uuid4())
        
        await self.send_message(user_id, {
            "type": "interaction_request",
            "request_id": request_id,
            "interaction_type": interaction_type,
            "payload": payload
        })
        
        timeout = 300
        start_time = time.time()
        
        while time.time() - start_time < timeout:
            feedback = self._wait_for_feedback(request_id, timeout=30)
            if feedback:
                return feedback
        
        return {"status": "timeout"}
    
    def _wait_for_feedback(self, request_id: str, timeout: int) -> Optional[dict]:
        """等待用户反馈（阻塞调用）"""
        redis_key = f"feedback:{request_id}"
        return self.redis.blpop(redis_key, timeout=timeout)

# dHash (Difference Hash) 变化检测
def detect_changes(self, screenshot):
    # 计算dHash值
    current_hash = self.calculate_dhash(screenshot)
    
    # 与上一次截图比较
    if self.last_hash:
        hamming_distance = self.calculate_hamming_distance(
            current_hash, self.last_hash
        )
        
        # 阈值判断 (默认为5)
        if hamming_distance > self.threshold:
            self.last_hash = current_hash
            return True
    
    self.last_hash = current_hash
    return False
```

            message = consumer.read_messages(
                stream_name=queue_name,
                consumer_group="orchestrator",

## 13. 总结

本架构设计文档v3基于项目实际代码逻辑，采用 **Orchestrator-Worker** 架构模式，通过 **LangGraph** 实现工作流编排，通过 **Redis Streams** 实现异步消息传递，通过 **ChromaDB** 实现知识库存储与RAG检索。

核心特点：
1. **状态驱动**: LangGraph状态机驱动工作流流转
2. **异步解耦**: Redis Streams实现服务间解耦通信
3. **智能编排**: 多Agent协同处理复杂业务场景
4. **容错设计**: 检查点机制支持工作流恢复
5. **可扩展性**: 插件化Agent和动态工作流节点
